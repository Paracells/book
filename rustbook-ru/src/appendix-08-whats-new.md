# Приложение H: Что нового в книге

Это приложение — журнал обновлений книги «Язык программирования Rust».
Здесь отмечены важные изменения текста и перевода, а также версии Rust,
с которыми согласована книга.

## Третье издание

Текущая версия книги — третье издание. По сравнению со вторым изданием в нём
произошли следующие основные изменения:

* Добавлена **глава 17 «Основы асинхронного программирования: Async, Await,
  Futures и Streams»**: введение в `async` и `await`, а также в типажи
  `Future` и `Stream`. Последующие главы перенумерованы.

* **Глава 20** (в предыдущих изданиях — глава 19) дополнена введением в
  [Miri][miri] — инструмент динамического анализа небезопасного кода. В ней
  также учтены важнейшие изменения Rust 2024 Edition.

* Исправлено множество мелких ошибок и неточных формулировок по всей книге.

* Текст книги предполагает использование Rust 1.98.0 и `edition = "2024"`.

Полное предисловие третьего издания с перечислением изменений доступно в
репозитории оригинала: [nostarch/frontmatter.md][frontmatter].

Список собирается по коммитам `rust-lang/book`, затрагивающим каталог `src/`:

```console
./rustbook-ru/tools/collect-upstream-changes.sh --write
```

После перевода новых изменений зафиксируйте новую базовую версию:

```console
./rustbook-ru/tools/collect-upstream-changes.sh --save-base
```

По умолчанию скрипт ищет клон оригинала в `../book-en` рядом с репозиторием
перевода; другой путь можно указать через `--repo`.

## Как следить за изменениями

* Оригинал книги: <https://doc.rust-lang.org/book/>,
  репозиторий <https://github.com/rust-lang/book>
* Русский перевод: <https://github.com/rust-lang-ru/book>

В локальном клоне репозитория:

```console
git log --oneline -- rustbook-en   # синхронизации английского оригинала
git log --oneline -- rustbook-ru   # правки русского перевода
```

Чтобы посмотреть, что изменилось в оригинале между двумя синхронизациями,
склонируйте [репозиторий книги][upstream] и выполните в нём:

```console
git clone https://github.com/rust-lang/book
cd book
git log --oneline -- src
git diff <старый-коммит>..HEAD -- src
```
